**발생한 버그 및 수정:**

- Supabase GRANT 권한 누락 (code: 42501) → GRANT 실행으로 해결
- Railway trust proxy 미설정 → ERR_ERL_UNEXPECTED_X_FORWARDED_FOR → app.set('trust proxy', 1)
- analyze.js 프로필 없을 때 500 → PGRST116 처리 후 자동 생성 로직 추가

**교훈:**

- Railway 등 리버스 프록시 환경에서 express-rate-limit 사용 시 trust proxy 필수
- CDN blob URL 사용 시 CSP의 img-src에 blob: 명시 필요
- 새 Supabase 프로젝트에서 기존 유저 로그인은 트리거가 안 터지므로 백엔드에서 프로필 자동 생성 필요
